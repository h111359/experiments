
RED Certification

Product Description
The RED Certification process is a component of the RED (Right Execution Daily) process, ensuring that strategic business tools are adopted effectively to drive shopper satisfaction. 

RED Certification tool is a web-based survey system for collection of RED performance data and providing reporting and analysis over it. By transitioning from manual Excel-based surveys to a web-based application, the project reduces costs and enhances functionality. 

The centralized system will feature a user interface for assessments, a database for storing results, and Power BI integration for data analysis and is planned for go live in 2025.
