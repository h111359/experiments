# Plan: R-20260702-1333

## Goal

Improve the AIB upgrade workflow to block the normal menu after `initialize.py --upgrade` completes and instead display a migration-completion screen that persists across terminal restarts, guiding the developer to execute `aib-modify.md` before confirming completion. Simultaneously rename the upgrade archive folder from `.aib_memory/archive/` (singular) to `.aib_memory/archives/` (plural) throughout the codebase.

**Background:** After upgrade the normal menu is shown immediately, misleading users into thinking migration of `context.md` is complete. A durable `memory_version_compatibility` field in `aib-setup.yaml` tracks the workflow position so the migration-completion screen is shown on every menu restart until the developer confirms.

**Impacted components:** `.aib_brain/tools/common.py`, `.aib_brain/tools/initialize.py`, `.aib_brain/tools/menu.py`, `tests/test_initialize.py`, `tests/test_menu.py`, `.aib_brain/README.md`, `.aib_brain/user_guide.html`, `.aib_memory/aib-setup.yaml`, `.aib_memory/context.md`.

## Constraints

- `memory_version_compatibility` is written and read only via `aib-setup.yaml`; no runtime flag or in-memory state.
- Trust model: no verification of migration execution; user confirmation accepted without checks.
- No migration of existing `.aib_memory/archive/` content; code change only.
- `edit-context.py` does not support the `File Structure` section; File Structure updates in context.md must be performed as direct text edits.
- `VALID_AREAS` in `edit-context.py` limits CRUD to: Product, Concepts, Requirements, Solution, Issues.
- `.aib_brain/` files (other than README.md and user_guide.html, which are explicitly listed) must not be modified without authorization — this request authorises changes to `common.py`, `initialize.py`, `menu.py`, and documentation files listed in scope.

## Success criteria

- Running `initialize.py --upgrade` on a versioned workspace writes `memory_version_compatibility: initialized-not-populated` to `aib-setup.yaml`.
- Fresh `initialize.py` run on a new workspace writes `memory_version_compatibility: compatible` to `aib-setup.yaml`.
- Starting `menu.py` when `memory_version_compatibility` is `initialized-not-populated` displays the migration-completion screen; pressing Confirm Completed sets field to `compatible` and shows the normal menu; pressing Exit exits.
- Starting `menu.py` when `memory_version_compatibility` is absent or `compatible` shows the normal menu unchanged.
- `.aib_memory/archive/` is no longer used by any code; new upgrade runs create subfolders under `.aib_memory/archives/`.
- All tests in `test_initialize.py` and `test_menu.py` pass after changes.
- `context.md` Solution and File Structure sections reflect the new archive path, new `memory_version_compatibility` key, and new migration-completion screen behaviour.

### Task 3: Update `menu.py` — migration-completion screen

#### Intent

Add a `_show_migration_completion_screen(workspace)` function that blocks the normal menu when `memory_version_compatibility` is `initialized-not-populated` and present "Confirm Completed" / "Exit" options. Wire it into `main()`.

#### Procedure

In `.aib_brain/tools/menu.py`, add a new `_show_migration_completion_screen(workspace: Path) -> bool` function. The function body must:

1. Call `clear_screen()` and write `ascii_banner()` to stdout.
2. Print a header line: `"  -- Migration Completion Required --"`.
3. Print explanation lines:
   - `"  The AIB memory upgrade is complete, but migration instructions still need to be executed."`.
   - `"  Open .aib_brain/prompts/aib-modify.md and execute it to reconstruct context.md from the archived legacy memory."`.
   - `"  Do not proceed until the migration prompt has completed successfully."`.
4. Print a blank line.
5. Print the options: `"  [1] Confirm Completed  — migration prompt has been executed successfully"` and `"  [2] Exit"`.
6. Enter a loop: call `input("  Enter choice [1/2]: ").strip()`.
   - On `"1"`: call `set_setup_option(workspace / ".aib_memory", "memory_version_compatibility", "compatible")`; print `"  Migration confirmed. Continuing to menu..."`; return `True`.
   - On `"2"`: return `False`.
   - Otherwise: print `"  Invalid choice — please enter 1 or 2."` and loop.

In `.aib_brain/tools/menu.py`, in `main()`, after the line `should_continue = check_version_compatibility(workspace, python_exe, tools_dir)` and the `if not should_continue: return` block, add:

```
compat_state = get_setup_option(workspace / ".aib_memory", "memory_version_compatibility")
if compat_state == "initialized-not-populated":
    if not _show_migration_completion_screen(workspace):
        return
```
