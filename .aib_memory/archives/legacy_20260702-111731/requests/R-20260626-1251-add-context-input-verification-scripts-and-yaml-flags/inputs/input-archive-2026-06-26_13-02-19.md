## Input

Goal: During context verification steps in `.aib_brain\prompts\aib-refresh-context.md` to use a python script which checks if the context is with the proper format and to indicate if not.
There is already existing script - .aib_brain\tools\verify-context.py, check if it is accordingly the latest context convention and use it in the prompts for context format verification. Also to be added the relationship between the prompts and this script in context so to future changes in the convention always to be reflected in the script as well.

Create similar script for input verification, which checks if the input is in the proper format and indicates if not. The script should be named `.aib_brain\tools\verify-input.py`. 

Add in `.aib_memory\input.md` in YAML header a flag to indicate if the input verification is enabled or not. The flag should be named `input_verification_enabled` and should be set to `true` by default. Add another flag to indicate the result of the verification, named `input_verification_result`, which should be set to `null` by default. If input_verification_enabled is set to `true`, the input verification script should be executed in the beginning of analysis prompt and the result should be stored in `input_verification_result`. If the input is valid, set `input_verification_result` to `valid`, otherwise set it to `invalid`.
Also in menu.py should be added a command to run the input verification script and display the result of the verification. The command should be named `verify_input` and should be available in the menu when the input verification is enabled. The script should update the `input_verification_result` flag in `.aib_memory\input.md` accordingly.

Similar to input verification, also add a flag to indicate if the context verification is enabled or not. The flag should be named `context_verification_enabled` and should be set to `true` by default. Add another flag to indicate the result of the verification, named `context_verification_result`, which should be set to `null` by default. If context_verification_enabled is set to `true`, the context verification script should be executed in the beginning of analysis prompt and the result should be stored in `context_verification_result`. If the context is valid, set `context_verification_result` to `valid`, otherwise set it to `invalid`. Also in menu.py should be added a command to run the context verification script and display the result of the verification. The command should be named `verify_context` and should be available in the menu when the context verification is enabled. The script should update the `context_verification_result` flag in `.aib_memory\input.md` accordingly.
