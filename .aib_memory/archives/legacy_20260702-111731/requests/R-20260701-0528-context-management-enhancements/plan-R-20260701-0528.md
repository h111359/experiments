### Task 7: Create `aib-sync-spec.md`

#### Intent

Create a new standalone interactive AIB prompt that synchronises `context.md` with an external specification file, auto-creating an AIB request, parsing the spec at sentence level, generating one Q-block per contradiction, and adding non-contradictory AI-classified items to context.md.

#### Procedure

1. Create the file `.aib_brain/prompts/aib-sync-spec.md` with the following phases and rules:

   **Phase 1 — Preflight:** Read `.aib_memory/instructions.md` (if present). Read `context-convention.md`. Read `context.md`. Run extension relevance check on `## References` entries with `Update:` lines. If `input.md ## Input` is empty, halt with error "No spec file path provided in input.md ## Input. Add the path and re-run." If `input.md` YAML header `status == idle`, invoke `create-request.py` to auto-create an AIB request. Log all preflight steps via `log-entry.py`.

   **Phase 2 — Spec Read:** Read the spec file path from `input.md ## Input`. Read the full content of the spec file at that path. If the file does not exist or cannot be read, halt with error citing the path.

   **Phase 3 — Sentence-Level Extraction:** Split the spec content into individual sentences. For each sentence, evaluate whether it contains a product-relevant statement that could be mapped to a `context.md` section (Product, Concepts, Requirements, Solution). Discard sentences that are structural (headings, metadata, formatting) without product content.

   **Phase 4 — Contradiction Detection:** For each extracted sentence, compare against existing `context.md` statements. A contradiction exists when the extracted sentence directly conflicts with an existing statement (not when it is merely new). Collect all detected contradictions.

   **Phase 5 — Q-block Generation:** For each contradiction, generate one Q-block in `input.md ## Questions` with the contradiction details and options: keep existing context statement, adopt spec version, merge both, or skip. Run `input-header.py --operation write --state questions_generated` and halt, waiting for developer answers. When answers are provided, re-evaluate contradictions and update context.md accordingly. Keep the reference to the spec file and the sentence in it in the Q-block.

   **Phase 6 — Apply Non-Contradictory Items (executed on re-run after Q-block answers):** For each non-contradictory extracted sentence, classify it: if the AI judges it as describing a future-intent feature not yet present in the workspace, use `edit-context.py --operation insert --area <section> --planned --text "<statement>"` to add it as a `[PLANNED]` entry; if the AI judges it as a current-state fact, use `edit-context.py --operation insert --area <section> --text "<statement>"` to add it as a plain entry. Apply answers to contradiction Q-blocks via the appropriate `edit-context.py` operations.

   **Phase 7 — Completion:** Log completion. Run `finalize-input.py` to archive and reset `input.md`.

2. Ensure the prompt file includes all standard AIB prompt structural elements: objective section, variables, global rules referencing GC-01 through GC-06, inputs table, outputs table, and numbered execution steps.
