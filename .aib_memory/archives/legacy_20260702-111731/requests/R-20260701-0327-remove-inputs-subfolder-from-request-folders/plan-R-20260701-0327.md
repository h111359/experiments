# Plan: R-20260701-0327

## Goal

Remove the `inputs/` intermediate subdirectory from request folder artifact layout. Currently `finalize-input.py` places the `input-archive-TIMESTAMP.md` file and moved attachments inside `<request-folder>/inputs/`. After this change both artifact types land directly at `<request-folder>/`. Seven downstream files that reference the old `inputs/` path must be updated to match the new flat layout. The change applies to newly finalized requests only; existing closed request folders are not migrated.

Impacted components: `.aib_brain/tools/finalize-input.py`, `tests/test_finalize_input.py`, `.aib_brain/prompts/aib-analyze.md`, `.aib_brain/prompts/aib-implement.md`, `.aib_brain/README.md`, `.aib_brain/user_guide.html`, `.aib_memory/context.md`.

## Constraints

- Do not migrate existing closed request folders; the layout change is forward-only.
- `create-request.py`, `move-request-artifacts.py`, and `close-request.py` are confirmed out of scope; do not modify them.
- All changes are path-string substitutions or word replacements; no behavioral logic changes.
- GC-04 in `aib-analyze.md` is confirmed out of scope (no change needed).

## Success criteria

- `python -m pytest tests/test_finalize_input.py -v` passes with 0 failures.
- `python -m pytest tests/ -v` passes with 0 failures (no regressions).
- No occurrence of `inputs/input-archive` remains in the seven listed files.
