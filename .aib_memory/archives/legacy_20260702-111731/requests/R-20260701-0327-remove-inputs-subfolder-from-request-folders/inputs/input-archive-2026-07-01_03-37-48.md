## Input

Remove the `inputs/` subfolder from all request folders. Currently, `finalize-input.py`
creates a `<request-folder>/inputs/` subdirectory and places two types of artifacts
there: (1) the input archive file (`input-archive-TIMESTAMP.md`) and (2) any attachment
files moved from `.aib_memory/attachments/`. After this change, both artifact types
MUST be placed directly in the request folder root (`<request-folder>/`), with no
`inputs/` intermediate directory. Attachment subdirectory structure (relative paths
from `.aib_memory/attachments/`) MUST be preserved, but rooted at `<request-folder>/`
instead of `<request-folder>/inputs/`.

Do not migrate existing requests; the change applies only to newly finalized requests.

The following artifacts contain the `inputs/` path and MUST be updated:

1. `.aib_brain/tools/finalize-input.py` — Remove `inputs_dir = request_folder / "inputs"`;
   replace all uses of `inputs_dir` with `request_folder` directly. Update all comments
   referencing the `inputs/` staging area.
2. `tests/test_finalize_input.py` — Update all test assertions that reference
   `<request-folder>/inputs/` to reference `<request-folder>/` directly.
3. `.aib_brain/prompts/aib-analyze.md` — Update GC-01 guard clause and S07 step
   descriptions that reference `<request-folder>/inputs/input-archive-*.md` and
   `<request-folder>/inputs/`.
4. `.aib_brain/prompts/aib-implement.md` — Update the MUST NOT guard clause that
   references `inputs/input-archive-*.md`.
5. `.aib_memory/context.md` — Update the Solution section statement about input
   archive path from `REQUEST-FOLDER/inputs/input-archive-TIMESTAMP.md` to
   `REQUEST-FOLDER/input-archive-TIMESTAMP.md`.
6. `.aib_brain/README.md` — Update the artifact table row for
   `inputs/input-archive-*.md` to reflect the new flat path.
7. `.aib_brain/user_guide.html` — Update two occurrences referencing the
   `<request-folder>/inputs/` path.
