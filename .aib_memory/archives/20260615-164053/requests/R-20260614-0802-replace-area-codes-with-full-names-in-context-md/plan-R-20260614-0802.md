## Goal

Replace all 22 two-letter area code identifiers (PO, CM, DO, etc.) throughout the AIB context subsystem with their full English names (Project overview, Change Management, Domain, etc.). The change starts at the authoritative definition in `context-convention.md`, then propagates to the two Python tool scripts that hardcode the same identifiers (`verify-context.py`, `edit-context.py`), then to the content file (`context.md`), and finally to two test files that use literal 2-letter codes in their fixtures. In the same implementation run, correct two factually incorrect statements in `context.md` that list Git as a required AIB runtime dependency (Git is only needed by the CI automation script, not by the core AIB workflow). The `--area` CLI argument of `edit-context.py` is updated to accept full area names (e.g., `--area Functionality`) per the developer's explicit choice.

Impacted components: `.aib_brain/conventions/context-convention.md`, `.aib_brain/tools/verify-context.py`, `.aib_brain/tools/edit-context.py`, `.aib_memory/context.md`, `tests/test_verify_context.py`, `tests/test_context_formatting_rules.py`.

## Constraints

- Statement type identifiers (N, R, C, D, I, U, A, E, L) are unchanged.
- Atomic statement lines in `context.md` are unchanged except the two Git dependency corrections and the two "area codes" → "area names" wording fixes.
- `context.md` reserved headings `## 1. Product Identity` and `## Files` are unchanged.
- `scripts/release_bookkeeping.py` is out of scope — its git dependency is a legitimate CI concern.
- `docs/Development_and_Deployment_Specification.md` and `user_guide.html` are out of scope — both are already factually accurate.
- `context-convention.md` MUST retain the `## <AREA>` template marker in its section structure description (test_context_formatting_rules.py line 56 depends on it).
- The ordering of areas in VALID_AREAS and AREA_ORDER across both tool scripts MUST remain identical to the current ordering, mapped to full names.
- All three sources (context-convention.md enumeration, verify-context.py VALID_AREAS, edit-context.py VALID_AREAS + AREA_ORDER) MUST contain identical area name sets after the change.

## Success criteria

- `python .aib_brain/tools/verify-context.py --workspace .` exits with code 0 and reports 10/10 checks passed.
- `python -m pytest tests/ -q` exits with code 0 and all tests pass.
- `context.md` area headings are all full names; no 2-letter area H2 headings remain.
- `edit-context.py --area Functionality --operation select --text "System must"` (against a suitable test context) resolves without error.
- The phrase "Python 3 and Git" does not appear in `context.md`.
- The phrase "22 valid area codes" does not appear in `context.md`.
