# Plan: R-20260611-1622

## Goal

Fix the bug where the AIB analysis workflow (`aib-analyze.md`) writes a pre-answered Q-block to `input.md`. The invariant is: every Q-block appended to `input.md ## Questions` during step S08 must be fully unanswered (all checkboxes `[ ]`, `- Answer: ___` verbatim). Only the developer may mark answers.

**Root cause (pending Q&A confirmation):** Two defects enable the bug:
1. `aib-analyze.md` Step S08 rules block lacks an explicit "MUST NOT pre-check any option; MUST NOT populate `- Answer:` field" constraint. The rules are permissive by omission, allowing an AI agent to mark a *(recommended)* option as `[x]` or fill the Answer field.
2. `analysis-convention.md` section 4.5 "Resolution outcome" instruction — "retain only chosen alternative; discard non-chosen from final doc" — is not qualified by DP state. For `ask` DPs, no alternative has been chosen; the AI may interpret this instruction as requiring pre-selection, and carry that selection into the Q-block.

A contributing aggravator: S08.1 promotes DPs from `resolve-autonomously` to `ask`. Those DPs already have a pre-chosen alternative recorded in the analysis. S08.2 generates Q-blocks for them without any rule preventing the pre-choice from appearing as `[x]`.

**Impacted components:**
- `.aib_brain/prompts/aib-analyze.md` — S08 rules block (primary fix location if Q001/Q002 answers select Option A or C)
- `.aib_brain/conventions/analysis-convention.md` — section 4.5 "Resolution outcome" (fix location if Q001/Q002 answers select Option B or C)
- `.aib_memory/context.md` — optional `## FN` entry (only if Q005 selects Option A)

## Constraints

- Fix must be minimal in token cost (one-line or few-word additions preferred).
- Fix scope is limited to the three files named above and `context.md`.
- `q-block-convention.md` must not be modified unless explicitly re-scoped.
- The `.aib_brain/` folder must not be modified during active implementation unless this request explicitly authorises it — this request does authorise targeted edits to `aib-analyze.md` and `analysis-convention.md` within `.aib_brain/`.

**Assumptions:**

- Success criterion: after the fix, the AI does not mark any checkbox `[x]` or populate `- Answer:` with non-placeholder content when writing Q-blocks during S08.
- `q-block-convention.md` and test files are out of scope.

## Success criteria
