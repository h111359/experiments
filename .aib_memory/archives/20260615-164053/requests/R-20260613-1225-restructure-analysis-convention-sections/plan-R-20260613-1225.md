# plan-R-20260613-1225

## Goal

**Request:** Restructure analysis convention sections (R-20260613-1225)

**Background:** Analysis documents produced by AIB are dense and hard to skim. Pain points identified: (1) the Requirements Gate Evaluation table renders eight rows even when every category passes; (2) the mandatory `## Files Read During This Analysis Run` section consumes vertical space with no decision-support value; (3) no plain-English section states the AI's intended solution before alternatives; (4) no rationale block helps junior contributors understand why an approach was chosen; (5) the technical detail consumed by the planner agent (Step 9) is interleaved with human-facing prose rather than isolated.

**Resolution:** Restructure `analysis-convention.md` to introduce six top-level mandatory sections (replacing the current five) in fixed order: Overview → Input Interpretation → Research Results → Proposed Solution → Decision Register → Technical Context (For Planner Agent). Remove the `## Files Read During This Analysis Run` mandatory section. Add `### Edge Cases` as a required sub-section of Research Results (between AI Agent critique and Requirements Gate Evaluation). Apply a conditional render rule to the Requirements Gate Evaluation (one-line summary when all-PASS, full eight-row table when any non-PASS). Update `aib-analyze.md` §S05 with generation instructions for the two new sections and the new render rule for §S05.5. Update `context.md` to replace the "five mandatory sections" atomic statement with "six". Add one absence regression test to the test suite.

**Impacted components:**
- `.aib_brain/conventions/analysis-convention.md` — mandatory section list and per-section rules
- `.aib_brain/prompts/aib-analyze.md` — §S05 generation instructions and §S05.5 render rule
- `.aib_memory/context.md` — atomic FN statement recording section count
- `tests/test_analysis_prompt_structure.py` — regression test for the removed section
