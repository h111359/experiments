## Input

.aib_brain/conventions/q-block-convention.md and .aib_brain/conventions/analysis-convention.md: the former requires a recommended option for every multiple-choice question while the latter requires ask alternatives to be neutral, creating a recommendation-neutrality conflict.

### Goal

Clarify the distinction between neutral analysis alternatives and recommended questionnaire options so AIB users and agents can consistently apply both conventions without interpreting them as contradictory.

### Background

.aib_brain/conventions/analysis-convention.md section 4.6 already distinguishes the two requirements: alternatives for unresolved ask Decision Points remain neutral in the analysis document, while corresponding multiple-choice Q-blocks follow the recommendation requirement in q-block-convention.md.

The request is to make this existing distinction clearer through wording and cross-references, preserving current behavior.

### Scope

Update:

- .aib_brain/conventions/analysis-convention.md


### Required Behavior

- Alternatives for unresolved ask Decision Points in the analysis document remain neutral and do not identify a preferred option.
- A recommendation in a Q-block does not constitute a user answer or resolve the associated Decision Point.
- The Q-block recommendation does not change the neutral alternatives recorded in the analysis Decision Register.
- The clarification preserves the Q-block convention's existing applicability to analysis questionnaires and clarification questions.

### Constraints

Preserve existing question formats, identifiers, unchecked options, free-text alternatives, answer handling, and clarification-history rules.

Keep q-block-convention.md authoritative for Q-block formatting and analysis-convention.md authoritative for analysis-document content.

The developer's scope decision was supplied in chat by selecting Option B: “Preserve the existing behavior, but make the distinction clearer through wording and cross-references in the two conventions.” This authorizes the specified wording and cross-reference edits to the named .aib_brain/ file.

### Out of Scope

Changing the recommendation policy, decision-resolution classifications, workflow execution, validators, or question-generation behavior.

### Acceptance Criteria

- Convention explicitly distinguish neutral analysis alternatives from recommended multiple-choice Q-block options.
- Review of the changes confirms that existing behavior and Q-block structure are preserved.
