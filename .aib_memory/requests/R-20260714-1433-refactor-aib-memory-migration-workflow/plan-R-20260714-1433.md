## Goal

Refactor the AIB memory migration workflow for request R-20260714-1433. The primary change is to extract the migration procedure from the generated `input.md` into a dedicated prompt file. This involves: (1) modifying `_generate_migration_input()` in `initialize.py` to emit a minimal prose activation block instead of the current embedded specification; (2) improving `aib-context-migration.md` to clarify source identification, fix a heading typo, add a post-migration verification step, and remove trailing whitespace; (3) updating `test_initialize.py` to match the new minimal input format; and (4) updating `context.md` to register the new prompt. The `memory_version_compatibility` lifecycle and `aib-modify.md` entry point are unchanged.

Impacted components: `.aib_brain/prompts/aib-context-migration.md`, `.aib_brain/tools/initialize.py`, `tests/test_initialize.py`, `.aib_memory/context.md`.

- The existing absent-context conditional in `initialize.py` (`context.md` absent from archive → reference `aib-refresh-context.md`) must be preserved exactly as today.
- The new `input.md` body must use `_build_input_seed()` as the base and append after the `## Input` section; no sub-headings under `## Input`.
- `aib-context-migration.md` must not gain an `## Execution Context` section (DP-05: Option B).
- `aib-context-migration.md` must reference only the legacy `context.md` as migration source; no optional-source guidance (DP-06).
- `aib-modify.md` must not be modified.
- `context-convention.md` and `verify-context.py` validation behavior must not change.
- All changes must conform to AIB convention files.
