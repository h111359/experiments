## Input

### Goal

Eliminate the "Industry knowledge" reasoning block from every future analysis document by removing its authoring rule from `analysis-convention.md`, so that AIB analyses no longer instruct the AI to gather or emit external benchmarking / industry-literature findings.

### Motivating Need

The Industry knowledge bullet inflates analyses with content that is unactionable, model-dependent, and non-deterministic, weakening the "current-workspace-only" grounding AIB depends on. Removing the mandate keeps `analysis-*.md` focused on workspace-scoped reasoning (pattern scan, AI critique, edge cases, requirements gate) and enforces "no external judgment" as the sole legitimate source of autonomous decisions.

### Stakeholders

- AIB user (developer running `aib-analyze.md`) — receives leaner, workspace-grounded analyses.
- AIB developer / maintainer — owns the convention change and the regression-test update.
- AI Automation Agent — must stop generating the `### Industry Knowledge` sub-section in future analysis documents.

### Scope (in-scope deliverables)

- Edit `.aib_brain/conventions/analysis-convention.md` §4.3 Research Results to delete the single `- Industry knowledge: best practices+external benchmarking; min 3 findings from established frameworks/OSS communities/industry lit; each with applicability assessment` bullet, leaving the remaining Research Results sub-blocks (workspace pattern-scan, AI Agent critique, Edge Cases, Requirements Gate Evaluation) in their current positions and preserving section ordering.
- Update `tests/test_analysis_prompt_structure.py`: delete the `test_best_practices_present` test method outright (it currently asserts the phrase "best practices" remains in `analysis-convention.md` and will otherwise fail).
- Update `.aib_memory/context.md` `## Solution` section only if an existing Solution bullet already describes the Research Results sub-blocks or lists "Industry knowledge" as an analysis component; if such a bullet exists, edit it via a plan-driven `edit-context.py delete` + `insert` pair to drop the Industry knowledge reference while preserving the surrounding sentence.
