## Input

I want to create extensions for the context.md file, which are referred from it and which are populated with additional information. The extensions should be able to provide more details, examples, or related topics that enhance the understanding of the main content in context.md.

The extensions should be registered in References section of context.md. The extensions MUST be in the form of additional markdown files in format `context-<extension-name>.md`.

Reference section in context.md should be changed from optional to mandatory, and it should include a list of all possible extensions. It should not be managed by the user - all extensions for which AIB has defined conventions should be listed during initialization. User should not change it, except for the `Read:` and `Update:` lines. Each extension entry in the References section should follow the current format, including the `Location:` and `Summary:` lines, and an optional `Update:` line to indicate whether the extension is writable or read-only. Also it must have a `###` sub-heading with the extension convention file, extension prompt file and `Read:` flag with possible values `yes` or `no`.

Initially the References section must include only extension `context-data-model.md` with `.aib_brain\conventions\context-data-model-convention.md` (existing already) and `.aib_brain\prompts\aib-refresh-context-data-model.md` (not existing - must be created) with the flag turned off. 

You must create the new prompt file `.aib_brain\prompts\aib-refresh-context-data-model.md` with a prompt that instructs AIB to refresh the context-data-model extension, including updating its content based on the latest information in context.md and any other relevant sources in the workspace like scripts, documentation or data. The prompt should also specify that the extension should be updated only if the `Update:` flag is set to true. All data models should be updated in the extension file, and any new data models found in the workspace files should be added to the extension. The prompt should also instruct AIB to remove any data models from the extension that are no longer present in context.md.

More extensions are supposed to be created in the future but this is out of scope for now.

In order to work with the extensions, another special prompt file should be created which to be executed every time the context.md file is read. This prompt file should be named `.aib_brain\prompts\aib-context-read.md` and it should instruct AIB when to read the registered extensions. The rule of thumb is that AIB should read the registered extensions only if the `Read:` flag is set to `yes`.

Change also the Update flag in the References section of context.md to receive values `yes` or `no` instead of `true` or `false`.
