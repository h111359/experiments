## Goal

Remove all log-file creation and writing behaviour from the AIB toolchain — specifically eliminating `.aib_memory/logs/` directory creation in `initialize.py`, stripping log-file-write code from `menu.py` while preserving live terminal streaming, and updating every test, documentation artefact, and `.gitignore` entry that references the now-absent directory. The workspace becomes simpler, with no transient log files generated during menu action execution.

## Constraints

- Python standard library only; no new runtime dependencies may be introduced.
- All existing tests must pass after modifications.
- AIB conventions must be preserved; `.aib_brain/` files other than the explicitly targeted tool and HTML files must not be modified.
- Live terminal streaming in `menu.py` must be preserved (`_stream_pipe` and `_run_and_tee` are kept; only file-write logic is removed).
- The root-level `logs/` directory (CI release logs) is entirely out of scope; no changes to it.

## Success criteria

- `python .aib_brain/tools/initialize.py --workspace .` does not create `.aib_memory/logs/`.
- Executing a menu action via `menu.py` does not create any file under `.aib_memory/logs/`.
- `python -m pytest tests/` exits with code 0 after all modifications.
- `user_guide.html` no longer contains the line `logs/              ← Tool execution and action logs`.
- `.gitignore` no longer contains the pattern `.aib_memory/logs/aib-action-*.log` or its comment.

### Task 2: Strip file-write logic from menu.py

#### Intent

Remove all log-file creation and write calls from `menu.py` while keeping `_stream_pipe` and `_run_and_tee` intact for live terminal streaming, and clean up `run_action` to remove the log path variable and its stale print statement.

#### Procedure

Delete the entire `_make_log_path` function from `.aib_brain/tools/menu.py` — this is lines 118–129, spanning the function definition and its body. The function signature is `def _make_log_path(action_id: str, workspace: Path | None = None) -> Path:`.

Update the `_stream_pipe` function signature in `.aib_brain/tools/menu.py` from `def _stream_pipe(pipe, dest, log_file, prefix, lock):` to `def _stream_pipe(pipe, dest, prefix, lock):`. Inside the function body remove the line `log_file.write(f"{prefix} {line}\n")` and `log_file.flush()` from the `with lock:` block. Remove the two lines in the `except` clause that write `log_file.write(f"[THREAD-ERROR] ...")` and call `log_file.flush()`. After these removals the `except` clause becomes an empty block; add `pass` to keep it syntactically valid.

Update the `_run_and_tee` function in `.aib_brain/tools/menu.py`. Change the function signature from `def _run_and_tee(command: list[str], log_path: Path, title: str, inherit_stdin: bool = False) -> int:` to `def _run_and_tee(command: list[str], title: str, inherit_stdin: bool = False) -> int:`. Update the docstring to remove the reference to `log_path`. Remove the outer `with open(log_path, "w", encoding="utf-8") as log_file:` context manager and its three header-write lines (`[START]`, `[CMD]`, and the flush). The `subprocess.Popen(...)` call, thread creation, `start()` calls, `proc.wait()`, `join()` calls, and `return proc.returncode` statement are all retained without change. Update the two `threading.Thread` calls that pass `log_file` as an argument: in each `args=(proc.stdout, sys.stdout, log_file, "[OUT]", lock)` and `args=(proc.stderr, sys.stderr, log_file, "[ERR]", lock)`, remove `log_file` so the tuples become `(proc.stdout, sys.stdout, "[OUT]", lock)` and `(proc.stderr, sys.stderr, "[ERR]", lock)`. Remove the two trailing `log_file.write(f"[EXIT] ...")` and `log_file.flush()` lines at the end of the former `with` block.

Update `run_action` in `.aib_brain/tools/menu.py`. Delete the line `workspace = Path(workspace_default)` (line 525). Delete the line `log_path = _make_log_path(action.get("script", title), workspace)` (line 526). Change the call `exit_code = _run_and_tee(command, log_path, title, inherit_stdin=False)` (line 530) to `exit_code = _run_and_tee(command, title, inherit_stdin=False)`. Delete the line `print(f"Log: {log_path}")` (line 536). Note: if `workspace_default` is not used elsewhere in `run_action`, ensure no other reference remains; if the variable is referenced only for `log_path`, the `workspace = Path(workspace_default)` line is safe to remove.

Verify the file is syntactically valid by running `python -m py_compile .aib_brain/tools/menu.py` and confirming exit code 0.
